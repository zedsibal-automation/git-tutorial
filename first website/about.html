Hi, I'm Oliver Sain

AI automation specialist. I build the workflows, break them, and show you how I fixed them.

I help small businesses get rid of repetitive work: chasing invoices, answering the same support emails, losing leads after hours. I build the automation, test it against messy real-world data, and then write about everything that went wrong so you don't have to find out the hard way.

Why I Started This Blog

When I started learning automation, almost every tutorial showed a perfect workflow that worked on the first try. Mine never did. The real learning happened in the failures: the wrong-client email, the double-booked calendar, the bot that invented a return policy.

So I started documenting the whole process, not just the polished result. Behind the Workflow is the blog I wish I had when I was starting out.

What I Do

  • Workflow automation: connecting your tools so repetitive tasks run on their own
  • AI-powered processes: using AI for classifying, drafting, and routing, with a human in the loop where it matters
  • Testing and reliability: stress-testing every build before it touches a real customer
  • Handoff and documentation: leaving you with a system your team can actually understand

How I Work

  1. Find the bottleneck. I start with the task that costs you the most time or money.
  2. Build the simplest version. A small workflow that works beats a clever one that breaks.
  3. Test it hard. Bad inputs, empty fields, duplicate triggers, and downed APIs.
  4. Launch with guardrails. Risky steps get human approval, and every run is logged.
  5. Review and improve. I check the results after launch and fix what the real world exposes.

Tools I Use

n8n, Make, Zapier, OpenAI, Claude, Airtable, Google Sheets, Stripe, Slack, and Gmail. I only recommend what I've used on real projects.
